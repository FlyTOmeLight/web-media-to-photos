项目更名为「存图夹」，继续同时支持小红书与 X。

- 扩展名、弹窗标题、安装目录（`~/Library/Application Support/存图夹/`）和连接器标识（`com.local.media-photos`）统一改为新名称。
- 仓库更名为 `FlyTOmeLight/web-media-to-photos`，发布包改为 `web-media-to-photos-1.7.0.zip`。
- 安装器会把旧的「红薯收藏夹」安装目录和 `com.rednote.photosaver` 清单移到废纸篓；卸载脚本同时清理新旧两套文件。
- 扩展 ID 不变，保存历史、偏好和已保存的照片都不受影响。
- 连接器协议仍为 3，但连接器标识已更换：升级时必须重新运行 `native-host/install.command`，再到 `chrome://extensions` 刷新扩展。

下载 `web-media-to-photos-1.7.0.zip`，替换扩展文件并在 `chrome://extensions` 重新加载。
