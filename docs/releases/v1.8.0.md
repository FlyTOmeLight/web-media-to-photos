新增五种可切换的弹窗外观，并修正本机连接器的 Native Messaging 标识。

- 弹窗顶部新增调色盘入口，可切换「原生轻巧」「珊瑚随收」「暗房精选」「林间藏品」「轻快贴纸」五种主题；「珊瑚随收」为默认外观。
- 主题只改变颜色、字体、圆角、材质和阴影，不会重置已选媒体、保存目的地或正在进行的后台任务。选择保存在本机 Chrome 存储，下次打开弹窗继续沿用。
- 修正连接器标识：Chrome 不接受带连字符的 Native Messaging 宿主名，现由 `com.local.media-photos` 改为 `com.local.media_photos`。安装器会把旧版清单移到废纸篓。
- 新增隔离的 ego lite 全链路 E2E，覆盖真实扩展、Native Messaging、连接器写入临时文件夹，以及小红书图片、GIF、实况照片、部分失败和 X 图片保存。

从较早版本升级时，请下载 `web-media-to-photos-1.8.0.zip`，重新运行 `native-host/install.command`，再到 `chrome://extensions` 刷新扩展。扩展 ID、保存历史、偏好和已保存的照片都不会改变。
