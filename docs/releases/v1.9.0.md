# 存图夹 v1.9.0

- 合并当前帖子的页面状态与可见媒体，补全可保存的视频地址；无法取得直接视频地址的媒体不再进入保存列表，保留媒体原编号。
- 集中管理弹窗保存会话，关闭重开后可恢复进度、停止任务和重试失败项；「继续选图」后不再重新展示已关闭的旧结果。
- 保存任务统一管理下载文件和实况配对目录，在成功、失败、取消或进度回调异常后释放临时资源。
- Photos 导入区分成功、明确失败和结果未确认。未确认项不计入成功历史，也不会随失败项重试；请先检查「照片」，再决定是否重新保存。

本版本使用连接器协议 4。更新后请重新运行 `native-host/install.command`，再到 `chrome://extensions` 刷新扩展。

## English

- Merge current-post page state and visible media, resolve saveable video sources, and preserve original media indices.
- Centralize popup save sessions so progress, stop and retry survive reopening; continuing selection keeps old results dismissed.
- Release temporary downloads and Live Photo pairing directories after success, failure, cancellation or a progress callback error.
- Distinguish confirmed, failed and unconfirmed Photos imports. Unconfirmed items are excluded from successful history and failed-item retries; check Photos before saving them again.

This version requires connector protocol 4. Rerun `native-host/install.command`, then reload the extension at `chrome://extensions`.
