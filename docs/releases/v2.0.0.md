# 存图夹 v2.0.0

- 纯快捷指令版升级为 2.0.0，一个 iPhone 快捷指令同时支持小红书笔记和 X 帖子。
- 分享内容优先，无分享输入时才读取剪贴板；支持 `xhslink.com`、`xhslink.cn` 和 `t.co` 短链，并校验返回内容与当前帖子的身份。
- 小红书保存图片、页面提供的 GIF 和实况静态封面；X 保存原图，GIF 和普通视频取最高码率直接 MP4。仅提供 HLS 的视频会明确跳过，不会用封面冒充视频。
- 媒体按原帖编号和类型列出，确认选择后才下载，最后批量写入「照片」。无效链接、身份不一致、无可保存媒体和取消选择都有明确提示。
- 快捷指令生成器新增 14 项离线回归，并已在 macOS 完成小红书图片、X 图片、GIF MP4 和普通 MP4 的真实保存验证。iPhone 已同步安装，用户确认保存 X 图片；其他手机平台和入口尚未逐项验证。

X 使用公开嵌入数据地址 `cdn.syndication.twimg.com`，当前验证 `token=0` 可用；这不是平台承诺的稳定接口契约。

## English

- Shortcuts-only version 2.0.0 uses one iPhone shortcut for Xiaohongshu notes and X posts.
- Share-sheet input is preferred; clipboard access happens only without share input. The flow expands `xhslink.com`, `xhslink.cn`, and `t.co`, then validates the returned post identity.
- Xiaohongshu saves images, source GIFs, and static Live Photo covers. X saves original images and the highest-bitrate direct MP4 for GIFs and videos. HLS-only videos are skipped explicitly instead of substituting a cover.
- Media are listed by original index and type, downloaded only after selection, then saved to Photos in one batch. Invalid links, identity mismatches, no saveable media, and empty selection have explicit messages.
- The shortcut generator now has 14 offline regressions. macOS completed real saves for Xiaohongshu images and X image, GIF MP4, and video MP4 posts. iCloud installed it on iPhone, where the user confirmed an X image save; other phone paths have not been individually verified.

X uses the public syndication endpoint `cdn.syndication.twimg.com`; `token=0` currently works in verified samples but is not a documented stable API contract.
