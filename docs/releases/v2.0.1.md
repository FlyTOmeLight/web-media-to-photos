# 存图夹 v2.0.1

- 修复 X 图片查看器把推荐帖图片一起收集的问题。现在只保留当前地址对应帖子的媒体，并跳过引用帖和推荐栏中的其他帖子。
- Mac 扩展按媒体身份恢复勾选。重新打开弹窗时，媒体重新排序或部分媒体消失都不会把勾选转移给其他图片。
- iPhone 快捷指令支持按原帖编号选择媒体后保存，图片复用已下载文件，视频按需下载；小红书首选图片地址无效时会尝试其他通过校验的地址。
- iPhone 可直接从本页下载 `cuntujia.shortcut`。Mac 用户继续下载 `web-media-to-photos-2.0.1.zip`。

## English

- Fixes X photo viewer collection pulling in images from recommended posts. Only media belonging to the status in the current URL is kept; quoted posts and recommendation rails are skipped.
- The Mac extension restores selected media by identity when media are reordered or removed.
- The iPhone shortcut selects media by original post index before saving, reuses downloaded Xiaohongshu images, downloads videos on demand, and tries the next valid Xiaohongshu image URL if the preferred URL is invalid.
- Download `cuntujia.shortcut` directly on your iPhone. The Mac release is available as `web-media-to-photos-2.0.1.zip`.
